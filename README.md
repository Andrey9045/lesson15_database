# Пульт охраны банка.

## Подготовка к запуску скрипта
-Скачайте репозиторий на свой ПК [по ссылке](https://github.com/Andrey9045/lesson15_database)
Для начала, необходимо проверить установлен ли pip.
В командной строке вбейте команду
```
pip --version
```
Должна вывестись версия pip, если нет, то его необходимо установить с помощью curl или wget
```
curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
```
или
```
wget https://bootstrap.pypa.io/get-pip.py
```
После загрузки скрипта запустите его с помощью пайтон
```
python get-pip.py
```
Если pip уже установлен и вы хотите его обновить до последней версии, выполните следующую команду:
```
python -m pip install --upgrade pip
```
## Создание виртуального окружения
Откройте командную строку и перейдите в скачанный вами репозиторий
Перейти в директорию можно следующей командой:
```
cd C:\ваш\путь
```
Вместо C:\ваш\путь укажите фактический путь.
Далее для создания виртуального окружения введите следующую команду
```
python -m venv myvenv
```
Для активации ВО введите следующую команду
```
myvenv\Scripts\activate
```
## Подготовка к запуску скрипта - установка необходимых модулей
Далее введите следующую команду для установки необходимых модулей
```
pip install -r requirements.txt
```

## Создание .env
Создайте файл .env
Содержимое файла:
```
DB_ENGINE=*****
DB_HOST=*****
DB_PORT=*****
DB_NAME=*****
DB_USER=*****
DB_PASSWORD=*****
SECRET_KEY=*****
DEBUG=*****
SECRET_KEY=*****
ALLOWED_HOSTS=*****
```
Заполните необходимую информацию
`DB_ENGINE` - Указывает тип базы данных, которую использует ваше приложение.
`DB_HOST` - Указывает хост базы данных. Это может быть IP-адрес или имя хоста.
`DB_PORT` - Порт, на котором работает база данных.
`DB_NAME` - Имя базы данных
`DB_USER` -  Имя пользователя для подключения к базе данных.
`DB_PASSWORD` - Пароль для указанного пользователя базы данных.
`SECRET_KEY` - Секретный ключ, который используется для криптографических операций в Django, таких как генерация токенов и шифрование данных.
`DEBUG` - Указывает, находится ли приложение в режиме отладки. Если установлено в True, то включаются дополнительные сообщения об ошибках и другие функции, полезные при разработке.
`ALLOWED_HOSTS` - Список хостов, с которых ваше приложение может принимать запросы. Это необходимо для защиты от некоторых видов атак.
